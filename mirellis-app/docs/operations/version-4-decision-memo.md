# Version 4 decision memo template

Use this template for the smallest reversible decision that could improve clarity, safety, availability, or self-guidance.

| Field | Required answer |
| --- | --- |
| Question | What precise consumer or operational problem needs a decision? |
| Evidence | What observations, consented aggregate data, research, support reports, and tests exist — and what are their limits? |
| Options | At least two credible options, including retaining the current version or doing nothing. |
| Recommendation | The smallest reversible action. |
| Boundary check | How does it avoid hidden inference, data expansion, engagement optimisation, health claims, or dependency? |
| Validation and rollback | Which tests/reviews run, when is it revisited, and how is prior state restored? |

No Version 4 proposal may silently rewrite live curriculum content or expand collection, targeting, or consent.
