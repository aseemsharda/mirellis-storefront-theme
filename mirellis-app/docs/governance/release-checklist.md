# Curriculum release checklist

Before a semantic, safety, evidence, or routing release:

1. Link a change request with affected IDs, exact diff, risk, evaluation, and rollback.
2. Record the change class and named required reviewers.
3. Update the transition dossier, authoring contract, explanation copy, data inventory, and acceptance tests.
4. Run curriculum integrity, route determinism, evidence integrity, accessibility, privacy, and regression tests.
5. Verify alternate, exit, minimum-route, deletion, and offline/local-first paths.
6. Record the release version and rollback target.

This checklist does not authorise a release by itself.
